# Intruva web app

Next.js 16 + TypeScript + Tailwind v4, exported as a static site. See the repository root
[`README.md`](../../README.md) and [`SETUP.md`](../../SETUP.md) for how to run it, and
[`ARCHITECTURE.md`](../../ARCHITECTURE.md) for how it is put together.

```bash
npm run dev     # http://localhost:3000 (or use ../../start.sh → :3001)
npm run build   # static export to ./out
npm run lint
```
